# ReLIFE dataset metadata

This folder contains public metadata catalogues used for the ReLIFE data assessment work.

## Files

- `metadata_datasets_relife.csv`: Metadata catalogue for ReLIFE datasets, exported from the original Excel workbook. It documents dataset-level attributes and FAIR/data-quality assessment fields such as title, description, metadata URLs, methodology, accuracy, completeness, spatial level, accessibility, licensing, and terms of use.

The catalogue supports the Task 2.4 metadata collection and FAIR assessment process for both dynamic and static datasets.
