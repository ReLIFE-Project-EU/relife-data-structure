# ReLIFE Dataset Metadata

This folder contains public metadata catalogues used within the ReLIFE data assessment and quality control process.

## Files

- `metadata_datasets_relife.csv`: Metadata catalogue for ReLIFE datasets, exported from the original Excel workbook. It documents dataset-level attributes and FAIR/data-quality assessment fields such as title, description, metadata URLs, methodology, accuracy, completeness, spatial level, accessibility, licensing, and terms of use.

The catalogue supports the metadata collection, harmonization, and FAIR assessment activities conducted within ReLIFE Task 2.4.

## Methodology

Metadata was collected from publicly available repositories, project databases, scientific publications, and direct communication with dataset providers where necessary.

A standardized metadata structure was applied across datasets to ensure consistent documentation and comparability between heterogeneous European building stock data sources.

The metadata collection process included information on:

- dataset description and methodology,
- spatial and temporal coverage,
- granularity and completeness,
- identifiers and references,
- access conditions and licensing,
- availability and download information.

Where applicable, additional quality control procedures were performed, including consistency checks, harmonization of units and formats, and comparisons with external reference datasets.
