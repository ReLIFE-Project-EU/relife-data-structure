# Dataset: Analysis of Estonian buildings Installed PV

## Description

This dataset contains information regarding the deployment of Photovoltaic (PV) solar panels on residential buildings across Estonia. It is the result of a machine learning pipeline that uses YOLOv11 for object detection and segmentation on high-resolution aerial imagery (orthophotos). The detected PV panels are spatially joined with building footprints from the Estonian Building Registry to calculate PV adoption over two distinct time periods.

## Variables Description

The dataset `buillding-pv.gpkg` contains the following key columns:

### Identifiers & Target
* `id_building` (Integer): Unique identifier for the building, derived from the Estonian Building Registry (`ehit_id`).
* `geometry` (Polygon): Geometry of the building (`EPSG:3301`)

* `pv_count_older` (Integer): The number of PV panels detected on the building, representing year range 2016-2020
* `pv_count_recent` (Integer): The number of PV panels detected on the building, representing year range 2022-2024
