# Dataset: Analysis of Building LST in Ferrara

## Description

This dataset contains the data representing residential buildings and their corresponding Land Surface Temperature (LST) statistics for the municipality of Ferrara. It is generated by combining building footprints with their non-built surrounding areas and extracting zonal LST statistics from multiple raster thermal images.

## Variables Description

The tabular dataset `buildings-lst.gpkg` contains the following key columns:

### Identifiers & Target
*   `id` (Integer): Unique identifier for the building.
*   `geometry` (Polygon): Geometry of the building (`EPSG:25832`)
*   `age_class` (String): Age class of the building, categorized into `'Before 1980'`, `'1980-2000'`, and `'After 2000'`.

### Land Surface Temperature (LST) Features

Values represent temperature statistics in Celsius (°C). Metrics are available for winter night image (`winter_night` prefix), summer  day image (`summer_day`), and summer night image (`summer_night`).
*   `<prefix>_lst_mean_building` (Float): Mean LST calculated directly over the building footprint.
*   `<prefix>_lst_std_building` (Float): Standard deviation of LST over the building footprint.
*   `<prefix>_lst_mean_sourround` (Float): Mean LST calculated in a 150-meter buffer surrounding the building, explicitly masking out other building footprints.
